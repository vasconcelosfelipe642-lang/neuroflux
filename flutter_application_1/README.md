# NeuroFlux (Flutter)

Cliente Flutter do projeto **NeuroFlux**.

Documentação completa (instalação, API, funcionalidades e fluxo do app): **[README.md](../README.md)** (PT) · **[README.en.md](../README.en.md)** (EN).

## Comandos rápidos

```bash
flutter pub get
flutter run -d windows
```

A API deve estar rodando em `http://localhost:3000` (veja `backend/` na raiz do repositório).
